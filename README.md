# Daily

> 🇧🇷 Uma aplicação web para guardar seus segredos de forma rápida e prática.  
> 🇺🇸 A web application to keep your secrets quickly and easily.

---

## 🇧🇷 Português

### 📌 Sobre o projeto
O **Daily** é uma aplicação web simples onde você pode guardar seus segredos 
e anotações pessoais de forma rápida e acessível a qualquer momento.

### 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

### 📂 Estrutura do projeto
Daily/
├── css/        # Estilos da aplicação
├── img/        # Imagens
├── js/         # Scripts JavaScript
├── index.html          # Página principal
├── cards.html          # Página de cards
└── configuracoes.html  # Página de configurações
